# 静态资源（assets）

本项目运行期依赖的静态资源统一放在这里，纳入版本管理（可直接替换）。

| 子目录 | 内容 | 来源 |
|---|---|---|
| `digits/` | 单字符数字模板 `0.png` ~ `9.png` | 由你（使用者）放入；用于 `src/template_match.rs` 的模板匹配识别 |

## 目录定位顺序

程序按以下顺序查找 `digits/` 目录（第一个命中即生效）：

1. 环境变量 `DELTA_OBSERVER_DIGITS`（可指向任意绝对路径，优先级最高）；
2. 可执行文件所在目录**向上逐层**追溯（最多 6 层）寻找 `assets/digits`（因此 `target/debug/` 下运行也能定位到项目根的 `assets/digits`）；
3. 当前工作目录下的 `assets/digits`。

> 与本项目历史上 `config/` 的追溯策略一致，开发期目录布局与打包后布局都能工作。
> 换模板图后需**重启程序**（模板在进程内一次性加载并缓存）。
